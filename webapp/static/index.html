레이아웃 템플릿
전체 화면 분할 방식을 선택하세요. 슬롯 수에 따라 자동 마운트됩니다.
우측은 선택된 템플릿의 슬롯들로 구성됩니다. 우측 세로 dock 아이콘 을 잡아 끌어 슬롯에 떨어뜨리면 그 슬롯의 위젯이 교체되고, 슬롯 헤더(⋮⋮)를 끌면 다른 슬롯과 swap됩니다. 배치는 자동 저장됩니다.
현재 배치
사용 가능한 위젯
시그널 정확도 (B10)
PSR/DSR (Bailey & López de Prado) 기반 통계적 유의도가 confirmed 시그널에 가중치로 적용됩니다. 임계가 높을수록 시그널이 적어지지만 정확도는 높아집니다.
0.40 (느슨) 0.65 (기본) 0.95 (엄격)
1 (단일도 OK) 2 (기본) 5 (5개 합의)
・ PSR ≥ 0.95: confidence +0.15
・ PSR < 0.50: confidence -0.15 (통계적 무의미)
・ DSR ≥ 0.90: 다중검정 통과 +0.07
・ 변경은 즉시 적용 — 차트 마커가 자동 갱신

중앙 인증 서버는 가입/로그인/ 어드민 승인을 한 곳에서 처리합니다. 배포 시 필수입니다 — 그래야 다른 사용자가 각자 자기 PC에서 가입하고 어드민이 어디서든 승인 가능.

설정 안 함 = 로컬 SQLite (개발용, 단일 PC만 가능)
설정 함 = 중앙 Worker (배포용, 모든 PC 공유)
서버 URL
Worker 배포 후 발급된 URL을 입력 (예: https://jiqt-auth.<계정>.workers.dev)
배포 가이드
Worker 코드는 auth-worker/에 준비됨.
1. npm install -g wrangler
2. cd auth-worker && wrangler login
3. wrangler d1 create jiqt-auth → 출력 database_id를 wrangler.toml에 붙여넣기
4. npm run db:init (스키마 적용)
5. wrangler secret put ADMIN_PASSWORD (어드민 비번)
6. npm run deploy → URL 발급
자세한 사항은 auth-worker/README.md 참조.
A6: 내 PC를 핸드폰에서 접근
Quick Tunnel 또는 정식 Tunnel URL을 중앙 서버에 등록하면, 다른 곳에서 /go/<username>으로 접근 시 내 PC로 자동 redirect.
중앙 인증 서버 설정 후 사용 가능
Cloudflare Tunnel로 외부(데이터/지하철/회사)에서 이 PC에 접속. PC가 outbound로 Cloudflare에 붙는 방식이라 라우터 포트 포워딩 불필요, 무료, HTTPS 자동.
